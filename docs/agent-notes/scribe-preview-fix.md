# Предпросмотр Scribe Pro в PyCharm

12.10.2026. Проверен установленный Scribe Pro 2026.2.11.

## Причина

Действие Pin as main file записывает `typst.pinnedMainFile` в настройки проекта,
но исходный `TypstPreviewEditor` передаёт в отдельный процесс `tinymist preview`
путь открытой главы. Поэтому глава отображается без оформления главного файла,
а ссылки на источники из `references.typ` не разрешаются.

## Локальное исправление

В установленном JAR изменён только выбор входного файла при запуске предпросмотра.
Добавлен `PinnedPreviewEntry.resolve`: читает закрепление из `PropertiesComponent`
проекта; если закреплённый файл существует, передаёт его Tinymist, иначе использует
открытый файл. Синхронизация текста открытой главы оставлена прежней.

JAR: `/home/slavita/.local/share/JetBrains/PyCharm2026.1/intellij-typst-plugin-2026.2.11.jar`.
Резервная копия, исправленный JAR и исходники правки:
`/home/slavita/.local/share/typst-plugin/backups/scribe-pro-2026.2.11-preview-fix-20261012/`.

Нужно перезапустить PyCharm. При смене закреплённого файла нужно переоткрыть вкладки
предпросмотра, поскольку входной файл выбирается при запуске процесса.
Обновление или переустановка плагина может заменить локальную правку. На другую
версию автоматически её не переносить: сначала проверить код запуска.

## Проверка

- Анализ байткода всех 51 методов изменённого класса прошёл BasicVerifier.
- Проверены выбор закреплённого main, отсутствие закрепления, отсутствующий файл,
  пустое значение и путь к каталогу; JVM запущена с `-Xverify:all`.
- Сравнение архивов: изменён только `TypstPreviewEditor.class`, добавлен только
  `PinnedPreviewEntry.class`; остальные записи побайтово совпадают.
- `tinymist compile main.typ` успешно собирает документ.
- Проверка встроенного предпросмотра после перезапуска остаётся за пользователем:
  прямого доступа к интерфейсу IDE в этой сессии нет.

## Откат

После закрытия PyCharm вернуть исходный JAR командой:

```bash
cp '/home/slavita/.local/share/typst-plugin/backups/scribe-pro-2026.2.11-preview-fix-20261012/original.jar' '/home/slavita/.local/share/JetBrains/PyCharm2026.1/intellij-typst-plugin-2026.2.11.jar'
```

Затем запустить PyCharm. Перед откатом проверить, что плагин всё ещё версии
2026.2.11: не заменять более новую версию старой резервной копией.
